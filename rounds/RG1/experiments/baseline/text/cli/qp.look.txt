(R5/T3) The looks (design records): list them, show one as JSON, or its CSS custom properties

Usage: qp look <COMMAND>

Commands:
  list  The registered looks, one per line: name, default scheme, note (default first)
  show  One look's whole record as JSON (fonts, type roles, colour roles of both schemes, spacing, surface, glyph, motion)
  css   The shell chrome's CSS custom properties of a look in a scheme, one per line
  help  Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
