# present

Sunucu (presenter) tarafı: derinlik kuralları (`depth`), hareket tasarımları (`motion`) ve
derlenmiş sahne üzerindeki piksel jestleri (`gesture`). Klasör bütçesi için bir arada;
dışa açık yollar `qp_grammar::depth`, `::motion`, `::gesture` olarak kalır.
Ne değildir: derleyicinin kendisi (`compile/`).
