(R6) The live Matriks connection: record raw messages, inspect a raw log (`docs/matriks/LIVE.md`). Values come from the environment (`scripts/live.sh`)

Usage: qp live <COMMAND>

Commands:
  record             Connect once (environment variables, `docs/DATA_ACCESS.md`), subscribe the clock and the price cards of `--symbols`, record every raw message under `fixtures/local/live/raw/` and print counts. Ends after `--seconds` or on halt
  symbols            Fetch the symbol list (REST meta) into `fixtures/local/live/meta.json` and write universe lists `u30.txt` (BIST30), `u100.txt` (BIST100), `utum.txt` (BISTTUM) and `uall.txt` (all BIST equities); prints only counts
  bars               Fetch settled REST bars into `fixtures/local/live/rest/` (sequential, paced)
  trades             (RP4/T1) Fetch historical trades (`trade.gz`, level 1 only) into `fixtures/local/trades/<SYM>/<start>_<end>.csv.gz`, in windows of at most `--window-days` calendar days (≤ 15, the endpoint's limit). A window already in the cache is never fetched again; every request is appended to `fixtures/local/trades/requests.jsonl` (counts only)
  compare            M22: build bars from raw logs with the live feed and compare them with REST bars (`qp live bars` files); prints only an aggregate table
  compare-trades     (RP4/T2, M27) Bars from the cached trades through the live bar builder (`BarMethod::Trades`) against settled REST bars; with `--raw`, also the card / trades / mixed source table. Prints only an aggregate table
  price-steps        (RP4/T2) The price card's `priceStep` against the BIST step table, and trade prices on that grid (aggregate counts only)
  export-trade-bars  (RP4/T2) Bars from the cached trades (M27 rules) as RP4 harness series (`fixtures/local/rp4/tradebars/full/<period>/<SYM>.bars`, `manifest.json`), with an optional check against the harness REST series (aggregate counts only)
  inspect            Aggregate statistics of a raw log (no market values)
  reset              (RP4/T5, K64) A person's reset of an endpoint halt — a multi-connect notice or unexplained server closes (A52) — after they checked why. Removes `fixtures/local/live-<key>.halted` only with a non-empty `--note`, which goes with the time into `live-<key>.halted.log`. Asks to type the key on a terminal; without one it needs `--i-am-human`. An agent never runs this on its own (`docs/matriks/LIVE.md`). No network
  help               Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
