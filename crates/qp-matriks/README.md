# qp-matriks

Matriks MQTT message layer (R6). Pure: no network, no clock, no randomness;
I/O only through a `Read`/`Write` the caller passes. Server side only — not a
dependency of `qp-wasm`.

## Contents

| Module | What |
|---|---|
| `messages` | prost types generated at build time from `proto/*.proto` |
| `fields` | field number → proto name per message (generated), `FieldSet` |
| `wire` | top-level field numbers present in a payload |
| `topic` | `mx/symbol/<SYM>[@lvl2]`, `mx/timestamp`, `mx/messenger`, `mx/user/<sub>/messenger`, `mx/user/<sub>/mx/...` |
| `symbol` | `SymbolBook`: price card state per symbol, initial vs update |
| `clock` | `TimeMessage` decoding, `MarketClock` (open/closed from `MX` only) |
| `notice` | `classify_notice`: multi-connect / disconnect / alert / metaupdate |
| `status` | `stockStatus` code → session phase ("seans evresi") |
| `rawlog` | `RawWriter` / `RawReader`: raw message log for record and replay |

## Proto origin (K62)

`proto/` holds the Matriks protos copied byte for byte from the reference
connector; they are never edited. Origin, commits, date and per-file SHA-256
are in `proto/PROVENANCE.md` and `proto/provenance.json`;
`tests/provenance.rs` checks the copy against that record (and against the
source repo when it is present locally).

Types are generated by `build.rs` with `protox` (pure-Rust protobuf compiler)
and `prost-build`; no `protoc` install is needed.

## Field presence

A field that did not arrive did **not** change; it is never read as 0.

- Proto2 `optional` fields are `Option<T>`; absent stays `None` (tested).
- `SymbolBook::apply` merges with protobuf semantics (`prost::Message::merge`):
  only fields present in the payload overwrite the state. Each event carries
  the `FieldSet` that arrived, `publishReason` and `stockStatus` if sent.
- The first message after a (re)subscription is `Initial`; call
  `resubscribed(symbol)` / `resubscribed_all()` when subscriptions are renewed.
  By default an initial **replaces** the state (it is a full picture, so no
  field stays stale); `InitialPolicy::Merge` merges it instead.
- `TimeMessage` is proto3: no presence. `TimeTick::fields` shows what was on
  the wire; absent and default (`false`, `0`) cannot be told apart.

## Raw log format (v1, little-endian)

```text
header = "QPMXRAW\0" | version u16 = 1 | reserved u16 = 0
record = body_len u32 | t_us i64 | kind u8 | topic_len u16 | topic | payload_len u32 | payload | crc32(body) u32
```

`t_us`: arrival time, UTC epoch µs (passed by the caller). `kind`: 1 message,
2 connection opened, 3 connection lost, 4 subscribed, 5 subscribe rejected,
6 note. A partial tail reads as `RawError::Truncated`, a damaged record as
`RawError::Corrupt`; all records before it are returned. Raw logs contain real
market data: they belong under `fixtures/local/` only.

Tests use hand-built messages with made-up symbols (`TEST1`) and prices; no
real data, no network.
