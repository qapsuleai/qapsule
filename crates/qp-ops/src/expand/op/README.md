# expand/op/

`op.rs`'in parçaları (RF1 S4): `expand_op` dağıtıcısının her `Op` kolu kendi fonksiyonunda,
gövdeler aynen. `series` (seri ve barlar), `view` (görünüm ve katmanlar), `finding` (olgu,
bulgu, anlatı, sunum), `people` (niyet, yorum, silme, kitle, öneri reddi). Gramer işlemleri
`gops.rs`'te, izleme işlemleri `watch.rs`'te, `undo` ve `remove` açılımı `undo.rs`'tedir.
