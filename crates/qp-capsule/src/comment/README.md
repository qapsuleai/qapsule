# comment/

Ajan yorumu denetiminin parçaları (`comment.rs` kök modülü taşır, burada konular durur):
`number.rs` metindeki sayıların okunması ve motor değerleriyle eşleşmesi, `lexicon.rs`
tavsiye ve yön sözcüğü listeleri, `check.rs` taslağın kanıta karşı denetimi (`validate`).
Yorum yazmaz, yalnız denetler; dışa açık yollar `qp_capsule::comment::…` olarak kalır.
