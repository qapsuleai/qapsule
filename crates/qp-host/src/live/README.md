# live/

`qp live` alt komutlarının konu dosyaları: ham günlük alıcısı ve kayıt (`record`), ham günlük
incelemesi (`inspect`), REST sembolleri, çubukları ve işlemleri (`rest`), REST ile kayıttan
kurulan çubukların karşılaştırması (`compare`), testler (`tests`). Argüman yapıları ve komut
dağıtımı `live.rs`'tedir. Bağlayıcının kendisi değildir (o `qp-live`'dadır).
