# replica/

`replica.rs`'in parçaları: otoriteyi izleme (`follow`: iletiler, olaylar, günlüğün aynası,
veri olayları, yeniden çözüm) ve gösterim kuralı (`judge`: iddiaların koşulu, uzlaştırma,
itiraz, bir iddianın yargısı). Otoritenin alanlarına dokunmaz; yalnız gizli dar yöntemleriyle.
Otorite değildir; motor girdisi yazmaz.
