# ops/expand/

`expand.rs`'in parçaları: `expand_op` (tek fonksiyon, bütün olarak `op.rs`'te; istisna isteği),
doğrulama yardımcıları (`checks`), yetki ve bağ denetimleri (`bind`), `remove`/`undo`
genişletmesi (`undo`) ve işlem özetleri (`describe`).
Uygulama değildir; değişiklikleri belgeye `apply` uygular.
