# capsule/

Kapsül yaşamı (`capsule.rs` motor bağlama ve koşucu): dizin (`capidx`), iddialar, itiraz,
yorumlar, izleme, hikâye, baş parçalar, dışa açık görünüm (`public`) ve `capsule.rs`'in
`impl Session` parçaları (okur, koşu, sorgular, izdüşüm, oturma, cümleler).
Kapsül motorunun kendisi değildir; o `qp-capsule` crate'indedir.
