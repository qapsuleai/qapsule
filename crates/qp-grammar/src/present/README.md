# present

Sunucu (presenter) tarafı: derinlik kuralları (`depth`) ve derlenmiş sahne üzerindeki piksel
jestleri (`gesture`). Klasör bütçesi için bir arada; dışa açık yollar `qp_grammar::depth`,
`::gesture` olarak kalır. Hareket tasarımları ve yalnız tasarıma ileten derinlik girişleri
RF1'den beri `qp-designs`'tadır.
Ne değildir: derleyicinin kendisi (`compile/`).
