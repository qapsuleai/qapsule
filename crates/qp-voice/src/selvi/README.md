# selvi/

Selvi sesinin yüzeyleri (`selvi.rs` giriş noktası, iki dilli dizgiler, süre birimleri ve
`Cx` bağlamı): `headline.rs` başlık, `detail.rs` ayrıntının ilk cümlesi (güven, eşik),
`clause.rs` son katılan olgu cümleciği, `holds.rs` hâlâ geçerli mi / ne zaman / nasıl kapandı,
`ledger.rs` karne satırı; hepsi `Cx` üzerinde `impl` bloklarıdır. Testler `tests.rs`'te.
