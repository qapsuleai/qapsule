# livehost/

Canlı barındırıcının (`livehost.rs`, `LiveRuntime`) konu dosyaları: REST çubukları, işlem
geçmişi ve onarım olayları (`rest`), girdiler ve onarım (`runtime`), saat tıkı, kapsül izleme
ve durum (`status`), bağlantı iş parçacığı ve alıcısı (`conn`), `qp_matriks::LiveFeed`
üstündeki akış (`feed`), testler (`tests`, `tests/`). Ağ protokolü değildir (o `qp-live`'da).
