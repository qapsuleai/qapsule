# `mixed` yüzeyinin parçaları

`../mixed.rs` yüzeyin kendisidir (`Mixed`, sabitler, araçlar ve `ToolSurface`); bu klasör
onun konu parçalarını tutar: argümanlar (`args`), `write` şemasının daraltılması (`schema`),
sonuçlar ve kapsül metinleri (`text`; `thin` yüzeyi de kullanır). Ayrı bir yüzey değildir;
kayıt `../registry.rs`'tedir.
